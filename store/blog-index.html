Start here if your exam is coming up

Three things trip up most candidates, and none of them is a lack of trade knowledge. The first is the clock: licensing exams are open book, and the people who run out of time are the ones who look up answers they should already know roughly where to find. Tab the code book yourself, read the table of contents until you can place any topic in its chapter, and drill the index with a timer. The second is calculations. Ampacity with correction and adjustment factors, voltage drop, box and conduit fill, motor circuits, dwelling loads and transformer sizing show up on every exam, and they are the easiest points to lose under pressure. Give them two sessions a week from the first week, not the last. The third is the edition. States move to new code cycles at different times; your candidate bulletin names the edition your test is written to, and the book you bring must match it.

The posts on this blog go deep on each of those, plus the licensing rules for individual states as they change. When a post is about one state, it links to that state's journeyman and master packages, which are built on the {{YEAR}} National Electrical Code and ship from our fulfillment center, {{FULFILL_NAME}}. If you want a plan rather than a reading list, the six-week study schedule is the place to begin, then come back for the calculations posts once you know which articles slow you down.

What we write about

Study strategy. How to split six or eight weeks so the code book, the calculations and the timed practice each get their turn; how to keep an error log that points at code sections instead of vague topics; what to do in the last three days, and what not to do the night before. These posts are written for people who work full days and study at the kitchen table, so every plan assumes about ninety minutes an evening.

Navigating the code. Which chapters carry most of the questions, how to tab a code book so the tabs are useful rather than decorative, how to use the index and the table of contents under time pressure, and how to read an exception without missing the condition that makes it apply. We also cover what changes between code cycles, because a question written to one edition can have a different answer in the next.

State licensing. Who issues the license, which testing vendor runs the exam, what counts as qualifying experience, how reciprocity works where it exists, and when a state moves to a new code edition. Boards change these rules without much notice, so each state post carries the date it was last checked and a link to the board's own page. When a rule changes, the post is updated rather than replaced, so the link you saved keeps working.
