## Open Book Test

New Mexico journeyman electrical examinations are listed as open-book examinations. Candidates are responsible for bringing their own approved references to the examination center. Reference materials must be bound and may be highlighted, underlined, and indexed before the examination session. Reference materials containing writing are not allowed, references may not be written in during the examination, and additional loose or attached papers are not permitted. Permanent tabs are allowed, while temporary tabs such as Post-it notes are not allowed.

Open-book testing still requires serious preparation. Having the NEC available does not mean the answer will be easy to find. Candidates must know how the code book is organized, how to identify the subject being tested, which article or table applies, and how to read technical code language accurately. Many missed questions happen because a candidate searches the wrong section, overlooks an exception, uses the wrong table, or applies a rule to the wrong installation condition.

The included NEC tabs are useful for building faster code-book navigation during study. Candidates can use the tabs to become familiar with major NEC chapters, frequently used articles, and important tables. Repeated practice helps turn the NEC from a difficult reference book into a more usable tool. This is valuable for open-book exam questions and for practical electrical work that requires accurate code interpretation.

A strong open-book study method is to answer a question, locate the related NEC section, read the complete rule, and then review why the answer is correct. Candidates should not rely only on memorizing answers. The better skill is learning how to find the rule, understand the language, and apply it to the condition described in the question.

Time management should also be part of open-book preparation. Candidates should practice deciding when to answer from knowledge, when to look up the code, when to calculate carefully, and when to mark a question for later review. Timed practice can help candidates build confidence and reduce stress when working through code-based questions.
