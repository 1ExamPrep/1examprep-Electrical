## Open Book Test

The Wisconsin DSPS Master Electrician exam information states that the exam is open book. DSPS also states that the passing score is 70%. Because reference materials are allowed under state rules, students should spend time learning how to use their code book efficiently before exam day.

DSPS provides specific reference-material rules for trades exams. Printed notes are allowed when they are three-hole punched and placed in a binder. Printed code may only be brought into the exam if it is bound together in a three-ring binder. Practice exams and previous exams do not qualify as notes and are not allowed. Tabs are acceptable when they come with a bound code book, and three-ring paper dividers with tabs are permitted. Loose papers, removable tabs, sticky notes, and paperclips are not allowed.

DSPS states that Pearson VUE and DSPS exam locations allow three reference item categories for the Master Electrician exam: one binder containing Wisconsin Administrative Code SPS 305, Wisconsin Administrative Code SPS 316, and printed notes; the National Electrical Codebook or Handbook edition listed by DSPS; and up to two printed, bound reference books such as common electrical reference books.

Students using this combo should treat the open-book format as a skill to practice. Fast code lookup comes from repetition. Candidates should practice moving through definitions, general requirements, wiring and protection, wiring methods, equipment rules, special occupancies, special equipment, and tables until the structure of the code book feels familiar.
