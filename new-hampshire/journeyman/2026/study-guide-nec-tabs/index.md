## Open Book Test

The New Hampshire journeyman electrician examination is an open-book examination. Authorized references may be used during the exam, and reference materials are checked by the test administrator before being allowed in the testing room. Candidates should review their current Prov candidate bulletin and state instructions for the exact approved reference list, code edition, marking rules, tabbing rules, and prohibited materials.

Open-book testing still requires serious preparation. Having the code book available does not mean the answer will be easy to find. Candidates must understand how the NEC is organized, how to identify the subject of a question, which article or table applies, and how to read code language accurately. Many incorrect answers happen because candidates search in the wrong section, overlook an exception, use the wrong table, or misunderstand the installation condition described in the question.

New Hampshire testing rules allow authorized references to be prepared using highlighting, underlining in pen, and permanent tabs. Handwritten notes are not allowed in any portion of a reference book, moveable tabs are not permitted, Post-it notes are not allowed, photocopied documents cannot be added to a reference book, and test-preparation study guides are not approved references for the testing center.

The included NEC tabs are designed to support open-book preparation by helping candidates become more comfortable moving through the code book during study. Tabs can help organize major NEC areas and make repeated navigation practice more efficient. Candidates should use tabs during study sessions to build familiarity with definitions, chapters, articles, and tables.

A strong open-book study method is to answer a question, locate the related NEC section, read the full code language, and then review why the answer is correct. Candidates should not rely only on memorizing answer choices. The stronger skill is learning how to find and apply the rule, especially for topics involving services, feeders, branch circuits, wiring methods, motors, control devices, equipment, special occupancies, and calculations.

Time management is also important. During an open-book exam, every question requires a decision: answer from knowledge, look up the code, calculate carefully, or mark the question for review. Timed practice can help candidates become more comfortable making those decisions while maintaining accuracy.
